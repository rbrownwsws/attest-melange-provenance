# rbrownwsws/attest-melange-provenance

Attests the [melange](https://github.com/chainguard-dev/melange) generated build provenance of a built package.

> **N.B.**
> 
> This action will not work with the raw `*.attest.tar.gz` files that melange outputs.
> 
> It requires you to extract and fix the broken melange output first
