# rbrownwsws/attest-melange-provenance

Attests the [melange](https://github.com/chainguard-dev/melange) generated build provenance of a built package.

> **N.B.**
> 
> This action is intended to be used with the [rbrownwsws/release-melange-package](https://github.com/rbrownwsws/release-melange-package) action.
>
> It will not work with the raw `*.attest.tar.gz` files that melange outputs.
